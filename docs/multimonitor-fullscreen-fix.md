# 多显示器全屏独立检测与防误休眠说明

在 2.1.1 版本中，DeskWeek 彻底优化了多显示器环境下的全屏休眠逻辑，解决在某一块屏幕全屏运行应用（如全屏看视频或打游戏）时，另一块屏幕上的日程表会被误暂停甚至消失的问题。

## 优化要点

1. **按屏幕独立判断全屏**
   - 过去只要任意一块显示器存在全屏应用，浮窗就会全局暂停；
   - 现在浮窗只关注自己所在的显示器。主屏全屏播放视频或玩游戏时，副屏上的 DeskWeek 日程表不受任何影响，始终正常显示并实时更新。

2. **跨屏幕窗口智能保护**
   - 如果浮窗被拖拽放置在两块屏幕交界处（跨屏展示），只有当两块屏幕同时被全屏程序覆盖时才会进入暂停休眠；只要有一部分仍在可见区域，就会继续保持更新。

3. **管理中心独立判定**
   - 管理中心（独立编辑窗口）与桌面浮窗各自独立判断全屏状态，桌面浮窗暂停不会误使另一块屏幕上的管理中心暂停。

4. **无缝休眠与恢复**
   - 浮窗所在屏幕真正进入全屏时，依然会智能暂停以节省系统渲染资源；退出全屏后即刻在原屏幕原位置自动恢复显示，正在编辑的草稿与日程数据完好无损。
