# 桌面层与动态壁纸兼容性说明

DeskWeek 是一款专为 Windows 设计的桌面级周历清单。本文档介绍 DeskWeek 的桌面附着原理、与动态壁纸软件（如 Wallpaper Engine）的配合情况，以及多显示器和虚拟桌面下的使用体验。

---

## 一、什么是“桌面层”？

很多桌面小工具会直接显示为普通窗口，这会导致它们经常遮挡正在使用的浏览器或工作软件，或者在点击其他窗口时意外退到最底层。

DeskWeek 采用了专门的**桌面层附着技术**：
- **贴合桌面背景**：浮窗直接嵌入在 Windows 桌面背景上（位于桌面壁纸之上、桌面图标之后）。
- **不抢占工作焦点**：当你日常打开浏览器、Office 或其他应用时，这些软件都会正常覆盖在 DeskWeek 上方，绝不会打扰你的日常操作。
- **随时切回查看**：只需最小化窗口或按下快捷键 `Win + D` 返回桌面，就能立刻看到本周日程。
- **纯净安全**：DeskWeek 不会修改你的系统壁纸文件，也不改动 Windows 系统的核心设置。

---

## 二、与 Wallpaper Engine 等动态壁纸的配合

许多用户习惯在电脑上使用 Wallpaper Engine 等动态壁纸软件。DeskWeek 在设计时充分考虑了与动态壁纸的共存：

### 1. 实际共存效果
- **正常层级**：实机测试表明，DeskWeek 能与运行中的 Wallpaper Engine 良好共存。浮窗默认位于动态视频/场景壁纸的上层，你可以一边享受动态壁纸，一边直观查看日程。
- **独立渲染**：DeskWeek 不会将自身代码强行注入到壁纸引擎中，彼此独立运行，互不干扰。

### 2. 常见问题与解决方法
- **切换壁纸后浮窗被遮盖**：
  - 部分动态壁纸在切换主题或重启时，可能会重新排布桌面的窗口顺序，偶尔把浮窗压在下方。
  - **解决办法**：右键屏幕右下角的 DeskWeek 托盘图标，点击 **“找回浮窗并重置位置”**，浮窗会立刻重新回到最前层。
- **壁纸软件设置建议**：
  - 在动态壁纸软件中，保持壁纸为默认的“桌面背景”层级，避免勾选“置顶显示”等特殊模式，以保证桌面小工具正常可见。

## 三、多显示器与 Windows 虚拟桌面

### 1. 多显示器支持
- **跨屏幕拖动**：浮窗支持在多台不同分辨率、不同缩放比例（DPI）的显示器之间自由拖动与缩放。
- **位置自动记忆**：程序会记住浮窗所在的屏幕与坐标，下次启动时自动恢复。
- **屏幕热插拔保护**：当断开副屏或调整显示器分辨率时，程序会自动检查浮窗位置，确保浮窗始终处于可见的工作区域内。如果不小心移出屏幕，可在托盘菜单中选择“找回浮窗并重置位置”一键居中。

### 2. Windows 虚拟桌面支持
- 管理中心内置了对 Windows 虚拟桌面的识别能力。当你创建了多个虚拟桌面并在不同桌面切换时，点击打开管理中心会优先在当前正在使用的虚拟桌面中展现，避免频繁跨桌面跳转。

---

## 四、全屏游戏与省电表现

- **智能休眠**：在运行全屏 3D 游戏或全屏观看视频时，浮窗会自动暂停画面刷新与动画，以节省显卡与 CPU 算力。
- **与动态壁纸的省电协同**：Wallpaper Engine 通常也会在检测到全屏应用时自动暂停渲染，两者协同进入节能状态；退出全屏后，两者都会即刻自动唤醒恢复。

---

## 五、透明浮窗模式搭配建议

在“管理中心 → 设置 → 浮窗背景”中开启 **“透明”** 模式后，浮窗的白色卡片底板将完全消除，文字将直接浮在壁纸上：
- **深色壁纸**：建议搭配“深色主题”，浮窗将使用清晰的白色/亮色文字。
- **浅色壁纸**：建议搭配“浅色主题”，浮窗将使用稳重的深色文字。
- **动态复杂壁纸**：如果壁纸画面较为杂乱或频繁变化，可根据喜好使用默认的“标准模式”（自带半透明圆角底板），阅读体验更加舒适稳定。
