DeskWeek 使用说明
更新日期：2026-11-09

一、快速上手与启动

1. 完整解压便携程序压缩包，建议放置在个人文件夹（如 D:\Tools\DeskWeek），避免放在受 Windows 保护的系统目录（如 Program Files），以免保存权限受限。
2. 双击 DeskWeek.exe 即可运行，浮窗会自动显示在桌面上。
3. 浮窗贴合在桌面背景层上，不会遮挡日常办公软件。最小化其他窗口或按快捷键 Win + D 即可查看浮窗。
4. 点击浮窗顶部的“管理”按钮，或点击屏幕右下角系统托盘中的 DeskWeek 图标，即可打开管理中心。
5. 如果看不到浮窗，可右键托盘图标点击“显示/隐藏浮窗”；若调整了分辨率导致浮窗跑出屏幕，点击“找回浮窗并重置位置”即可一键回到主屏幕中央。

二、系统托盘菜单说明

- 管理中心：打开独立的事项管理窗口。
- 显示/隐藏浮窗：临时显示或隐藏桌面浮窗，已有事项保持不变。
- 找回浮窗并重置位置：将浮窗立刻召回并居中在主显示器。
- 浮窗状态：查看浮窗当前运行状态（正常桌面层、休眠暂停中等）。
- 退出：关闭程序；退出前请确保已保存正在编辑的文字。

三、日常功能亮点

- 多视图切换：支持年、月、周、日四种日历视图，方便长远规划与近期待办查看。
- 提前与延后显示：在未完成页底部可展开“延后显示”栏，查看设定了延后展示的事项。
- 跨屏幕拖动：支持自由拖动到任意副屏幕，并自动记住位置。
- 全透明浮窗模式：在“管理中心 → 设置 → 浮窗背景”中可开启“透明”模式。该模式去除了卡片底板与阴影，只保留日程文字，完美融入各类壁纸风格；支持配合浅色或深色主题自由搭配。

四、智能节能休眠

- 当全屏打游戏、全屏播放视频或电脑锁屏时，浮窗会自动暂停刷新和动画以节省硬件资源。
- 退出全屏后，浮窗会在 1~2 秒内自动恢复显示。
- 如果浮窗中有正在编辑且未保存的文字，程序会优先保护用户输入，不会强行关闭界面。

五、数据保存与数据迁移

- 纯本地存储：所有任务保存在程序旁的 data\data.json，并会自动保留最近一次的备份（data\data.json.backup）。
- 安全保存：遇到断电或异常时，程序会尝试自动从备份恢复，防止数据丢失。
- 迁移电脑：只需将整个 DeskWeek 文件夹（特别是 data 目录）复制到新电脑即可直接使用。
- 软件升级：手动下载新版本解压后，将原有的 data 文件夹复制到新版本目录中，即可无缝沿用历史任务和配置。
