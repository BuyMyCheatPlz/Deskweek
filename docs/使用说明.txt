DeskWeek 使用说明
更新日期：2026-11-09

一、启动并在桌面显示

1. 完整解压便携程序文件夹，不要直接在压缩包里运行，也不要只拷贝 DeskWeek.exe。
2. 双击 DeskWeek.exe，浮窗会自动显示在桌面层；普通应用窗口可以遮住它。
3. 返回桌面查看浮窗。程序不替换壁纸，不需要把 Wallpaper Engine 壁纸设置成 DeskWeek。
4. 点击浮窗上的“管理”，或点击右下角系统托盘中的 DeskWeek 图标，打开管理中心。
5. 看不到浮窗时，右键托盘图标，选择“显示/隐藏浮窗”；位置异常时选择“找回浮窗并重置位置”。托盘图标可能在系统的隐藏图标区域中。

建议放在当前用户可写的普通文件夹。Program Files 等受保护目录可能导致保存失败。
程序未进行 Windows 代码签名，首次运行可能出现“未知发布者”提示，请核对程序来源。
目标平台为 64 位 Windows 10 / Windows 11；本轮只在当前 Windows 主机验证，未覆盖所有系统版本。

二、托盘菜单

管理中心：打开独立管理窗口。
显示/隐藏浮窗：切换浮窗显示状态，不删除事项。
找回浮窗并重置位置：重新显示浮窗，并重置到主屏工作区内。
浮窗状态：显示“桌面层”、“暂停刷新”或兼容窗口的原因。
退出：结束程序；退出前先保存正在编辑的内容。

三、日常使用

浮窗可查看日历、添加和管理待办；管理中心可编辑事项、调整主题和配置可选 AI 功能。
未完成页底部的“延后显示”折叠栏可查看暂时不在清单中的事项。
浮窗是单个窗口，可以移动到其他显示器，并非每块屏幕各显示一份。
桌面附着失败时会降级为普通窗口，托盘状态会显示原因。

透明背景：打开“管理中心 → 设置 → 浮窗背景”，选择“透明”。主界面的白色/乳白色底板、卡片填充、磨砂和厚重阴影会去除，只保留日历、任务状态和必要操作，装饰标记与鱼挂件隐藏。
浅色主题使用深色文字，适合浅壁纸；深色主题使用浅色文字，适合深壁纸。编辑弹窗和日期/时间选择器使用深色半透明浮层。
背景选项会保存并立即同步到浮窗，重建后继续保留；选择“标准”即可恢复原背景。默认仍为标准模式。

四、暂停刷新与自动恢复

任意显示器上存在被识别为真正全屏的应用时，程序会暂停定时刷新和动画；锁屏、休眠以及主动隐藏浮窗也会触发暂停。
持续暂停约 15 秒后，只有浮窗确认没有未保存输入、打开的对话框、AI 请求或待完成保存，才会释放浮窗渲染器。主进程和托盘继续运行，内存不会降到零。
退出全屏、解锁或唤醒后，如果没有其他暂停原因且浮窗没有被主动隐藏，会自动重建浮窗。全屏状态约每 1.5 秒检测一次，恢复还需要页面加载时间。
管理中心不会因资源策略而被销毁；仅隐藏浮窗不会暂停仍可见的管理中心。
当前版本已修复 NVIDIA 全透明覆盖层导致的误暂停，以及恢复时访问已销毁窗口的报错。若仍出现只闪一下或错误弹窗，请查看同目录的“故障排查.md”。

五、数据、备份与更新

任务保存在程序旁的 data\data.json，最近一次有效主文件会作为 data\data.json.backup 保存。
窗口位置保存在 data\window-state.json；AI 配置和加密密钥也保存在 data 中。
迁移程序时携带完整程序目录及 data 文件夹。密钥依赖系统加密环境，换电脑或用户后可能需要重新填写。
浮窗草稿只暂存在当前主进程中，用于窗口重建后的恢复；退出、重启或主进程崩溃后不能保证恢复，请先保存。
更新前先保存编辑内容并备份 data 文件夹。不要删除 data 来解决浮窗显示问题。
不要从源码执行打包命令去覆盖日常使用、含 data 的程序目录，应在独立目录构建。
