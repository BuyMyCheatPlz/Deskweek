# 第三方开源项目与素材致谢 (Attributions)

DeskWeek 的开发与运行借鉴并使用了以下优秀的开源项目与素材，在此向所有原作者与贡献者表示衷心感谢：

## 开源项目

- **Windows 桌面附着实现**：`src/main/desktop/desktop.cjs` 与 `i18n.cjs` 参考并改编自开源项目 [Dayboard](https://github.com/nowsummer/Dayboard)（MIT 许可）。
- **农历、节气与传统节日**：使用 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT 许可），内置于程序中，本地离线计算，无需联网。
- **文档资料解析组件**（用于 AI 提取待办）：
  - Word 文档：[mammoth](https://github.com/mwilliamson/mammoth.js) (BSD-2-Clause) 与 [word-extractor](https://github.com/morungos/node-word-extractor) (MIT)
  - Excel 表格：[SheetJS](https://github.com/SheetJS/sheetjs) (Apache-2.0)
  - PDF 文本提取：[pdf-parse](https://gitlab.com/autokent/pdf-parse) (MIT)
  - 压缩包读取：[JSZip](https://github.com/Stuk/jszip) (MIT)

## 界面素材

- **“大肥鱼”挂件**：迷你浮窗中使用的“大肥鱼”卡通形象为应用界面装饰素材，版权归原作者所有。
