# AI 导入：从资料到待办

> 2026-11-11 · DeskWeek 2.2.0

桌面版现在有两条 AI 导入入口，都会把结果真正写入“未完成”待办：

1. **设置 → AI 导入**：粘贴文字、添加文件或图片，点“AI 拆解”，勾选要保留的事项，再点“导入选中”。
2. **浮窗/管理中心的“记一件事” → AI 总结**：同样的资料入口，拆解后会出现醒目的“全部导入”结果条；单条结果会先填入表单，再点“导入到待办”。

## 这次修了什么

之前 AI 总结完成后，结果卡片和“一键添加”按钮都在滚动区下方，用户看到的只有总结框，很难找到真正写入待办的动作；部分模型返回裸 JSON 数组时还会解析失败。现在：

- 总结完成后自动滚动到结果条，“全部导入（N）”就在结果旁边，不再被长表单挡住。
- 单条结果也有明确的“导入到待办”，不再只依赖最底部的“添加”。
- 结果列表里某一条标题/日期/时间不完整时，只跳过这一条并标红，不再让整批导入静默失败。
- 兼容模型返回 `{"items":[...]}`、裸数组 `[...]`、`{"tasks":[...]}` 三种形状。
- 设置页新增完整的 AI 导入面板：资料、补充要求、文件、图片、勾选、批量导入一次完成。

## 支持的资料

| 类型 | 格式 |
| --- | --- |
| 文本 | txt、md、markdown、json、xml、yaml、yml、log、csv |
| 文档 | pdf、doc、docx、odt、rtf、pptx |
| 表格 | xls、xlsx、xlsm、ods、csv |
| 图片 | png、jpg/jpeg、webp、gif |

限制：最多 5 个文件，单个不超过 20MB；最多 4 张图片，单张不超过 6MB；单个文件最多读取 6 万字，合计 12 万字。扫描版 PDF 没有文字，建议把页面截图作为图片添加。

## 隐私

文件解析在电脑本机的后台工作线程中完成，设置了内存上限和 30 秒超时。只有提取出的文字和你主动添加的图片会发送到你配置的 OpenAI 兼容接口；接口地址、模型和加密保存的 API Key 都在“设置 → AI 总结”里维护。
