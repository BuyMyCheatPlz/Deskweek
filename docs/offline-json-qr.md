# JSON 二维码离线传输指南

> 2026-11-11：已支持 [二维码容量优化](qr-density.md)，默认开启智能无损压缩，大幅减少扫码张数，并支持切换旧版兼容模式。

DeskWeek 支持通过二维码在电脑、手机和平板之间面对面互传日程数据。传输完全在本地完成，不需要处于同一个局域网，也不需要互联网连接。

## 使用方法

在管理中心进入「设置 → 离线传输与备份」：

- **生成 JSON 二维码**：点击后会展示包含当前任务数据的二维码。手机或平板打开 DeskWeek「设置 → 扫描二维码」对准屏幕扫描。如果数据较多，会自动分成多张，支持手动翻页或每 3 秒自动翻页，收齐全部页面后点击导入。
- **摄像头扫码导入**：手机在设置中点击「展示二维码」，电脑点击「摄像头扫码导入」打开摄像头对准手机扫码。支持切换摄像头、清空进度与重试；关闭扫码窗口即刻停止摄像头，画面不上传。
- **导入/导出 JSON**：传统的本地文件备份依然保留，导出的 `data.json` 可以在各端自由导入。

## 导入模式

扫描完成后，系统会提示你选择导入方式：

- **合并**：保留本机已有的其他任务；如果导入的任务与本机某条任务 ID 相同，会更新该任务的内容、完成状态或垃圾箱状态。你的个人界面偏好保持不变。
- **替换全部**：用导入的任务列表完全替换当前所有任务。请在确认覆盖前做好备份。

## 数据完整性与安全

- **数据完整校验**：多张二维码包含批次号、分页序号与 SHA-256 校验码，支持任意顺序扫描、重复扫描；只有完整收齐且校验无误后才会提示导入，不会写入错误或残缺的数据。
- **面对面安全**：二维码内容为任务明文，请只扫描自己信任的设备所展示的二维码。
- **容量建议**：如果任务数量较多（超过 20 页二维码），建议使用 USB 或文件传输方式导出 `data.json` 导入，更加快捷方便。
