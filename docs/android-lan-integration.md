# Android 客户端与多端同步指引

DeskWeek 现已支持 Windows 桌面端与 Android（手机和平板）客户端协同使用，提供两种便捷的数据互通方式：**离线二维码面对面传输**与**局域网同步**。

## 两种数据互通方式

| 方式 | 适用场景 | 操作步骤 |
| --- | --- | --- |
| **二维码离线传输（推荐）** | 两台设备面对面，无需同一网络或联网 | 电脑生成二维码，手机直接扫码导入；或手机展示二维码，电脑摄像头扫码 |
| **局域网同步** | 处于同一 Wi-Fi 或局域网，日常自动协同 | 开启同步开关，首次核对 6 位数字验证码配对，之后自动连接 |
| **文件导入导出** | 备份或通过 USB / 微信拷贝 | 导出为 `data.json`，在另一端选择合并或替换导入 |

## 1. 离线二维码传输

电脑与手机不需要连在同一个网络里，随时随地都能传：

- **电脑 → 手机**：在电脑管理中心的「设置 → 离线传输与备份」点击「生成 JSON 二维码」；手机打开 DeskWeek「设置 → 扫描二维码」，对准屏幕扫码后即可选择合并或替换。
- **手机 → 电脑**：手机点击「展示二维码」；电脑点击「摄像头扫码导入」，对准手机屏幕扫描即可。
- **数据安全**：二维码直接承载任务数据，完全在本地识别处理，不经过任何第三方服务器。数据较大时会自动分页并带校验码，收齐后才可导入，不会写入残缺数据。

详见 [JSON 二维码离线传输指南](offline-json-qr.md)。

## 2. 局域网同步

在同一个 Wi-Fi 或局域网环境下，设备之间可以自动发现并协同更新：

1. **开启同步**：在桌面端管理中心「设置 → 局域网同步」打开开关；
2. **连接配对**：手机端在设置中搜索电脑或输入电脑 IP 地址与端口，点击同步；
3. **核对验证**：两端屏幕上会显示相同的 6 位验证码，双方点击确认完成配对；
4. **日常协同**：配对成功后，两端只要在同一个局域网内即可自动发现并交换日程。

## 3. 数据安全与隐私

- **本地优先**：所有待办事项优先保存在本地文件（`data/data.json`），断网时不影响任何本地使用。
- **合并与冲突防护**：两端同时修改了不同任务时会自动合并；若同一任务的同一内容发生冲突，会保留候选内容供你选择，绝不静默丢失数据。
- **端到端加密**：局域网传输采用 TLS 加密保护，只有已配对的受信任设备才能互通。
